# 06. 배포·운영 체크리스트

체크리스트는 “한 번 하고 끝”이 아니라 변경 종류에 따라 다시 실행하는 운영 도구입니다. 날짜와 확인자를 함께 기록하면 좋습니다.

## 1. 커밋 전

- [ ] `git status -sb`로 의도하지 않은 변경이 없는지 확인했다.
- [ ] UTF-8 파일을 잘못된 인코딩으로 다시 저장하지 않았다.
- [ ] 새 페이지를 navigation, sitemap, 검증 대상에 반영했다.
- [ ] 외부 서비스 식별자와 엔드포인트를 확인했다.
- [ ] 비밀 키, 토큰, 개인 이메일이 커밋에 포함되지 않았다.
- [ ] 번호 생성 결과를 예측 또는 수익 보장처럼 표현하지 않았다.

## 2. 자동 검증

```powershell
node .\scripts\verify.mjs
```

- [ ] 명령이 종료 코드 0으로 끝났다.
- [ ] 8개 페이지가 검사되었다.
- [ ] 내부 링크, title, canonical이 통과했다.
- [ ] 번호 범위·중복·정렬 검사가 통과했다.
- [ ] 테마 저장 검사가 통과했다.
- [ ] 새 요구사항이 생겼다면 검증 코드도 추가했다.

## 3. 로컬 브라우저 확인

간단한 로컬 서버를 사용할 수 있습니다.

```powershell
python -m http.server 8000
```

- [ ] 홈과 7개 하위 페이지가 열린다.
- [ ] CSS와 JavaScript 요청이 404가 아니다.
- [ ] 번호가 5세트 생성된다.
- [ ] 테마가 전환되고 새로고침 후 유지된다.
- [ ] 키보드로 주요 링크와 버튼에 접근할 수 있다.
- [ ] 320px 안팎의 좁은 화면에서 가로 스크롤이나 겹침이 없다.
- [ ] 개발자 도구 콘솔에 예외가 없다.

## 4. URL·검색 확인

- [ ] 대표 주소가 사용자 사이트인지 프로젝트 사이트인지 기록했다.
- [ ] 모든 canonical이 대표 주소를 사용한다.
- [ ] JSON-LD의 URL이 대표 주소와 일치한다.
- [ ] `sitemap.xml`에 모든 공개 페이지가 있다.
- [ ] `robots.txt`가 올바른 sitemap을 가리킨다.
- [ ] GitHub Pages 설정의 브랜치와 폴더가 의도와 같다.
- [ ] Search Console 속성과 sitemap 제출 주소가 일치한다.

## 5. 외부 서비스 확인

### Formspree

- [ ] 배포 사이트에서 테스트 문의가 전송된다.
- [ ] 수신함 또는 대시보드에서 확인된다.
- [ ] 필수 동의, 스팸 방지, 회신 주소가 동작한다.
- [ ] 개인정보 안내와 실제 수집 항목이 일치한다.

### Disqus

- [ ] 댓글 UI가 로드된다.
- [ ] 페이지 식별자가 중복되지 않는다.
- [ ] 신고·삭제·스팸 관리 권한이 확인된다.
- [ ] 스크립트 차단 시 페이지 핵심 기능은 유지된다.

### AdSense

- [ ] 계정 메타, 로더, `ads.txt`의 게시자 ID가 일치한다.
- [ ] 로더가 페이지마다 한 번만 있다.
- [ ] 계정 및 사이트 심사 상태를 확인했다.
- [ ] 광고 때문에 콘텐츠 이동이나 과도한 레이아웃 변화가 없다.

### Google tag와 Clarity

- [ ] 측정 ID가 의도한 속성과 일치한다.
- [ ] 모든 공개 페이지에 중복 없이 있다.
- [ ] 실시간/디버그 화면에서 테스트 방문이 확인된다.
- [ ] 개인정보처리방침에 실제 사용 사실이 반영되었다.
- [ ] 민감한 폼 값이나 문의 내용이 분석 이벤트로 전송되지 않는다.

## 6. 배포 후

- [ ] GitHub Pages 빌드가 최신 커밋으로 성공했다.
- [ ] 대표 URL과 주요 하위 URL이 HTTPS로 열린다.
- [ ] 새 브라우저 또는 시크릿 창에서도 확인했다.
- [ ] 모바일 실제 기기에서 핵심 흐름을 확인했다.
- [ ] 배포된 소스의 측정 ID와 정책 문서가 커밋과 같다.
- [ ] 장애 시 되돌릴 커밋을 알고 있다.

## 7. 정기 운영

### 매주 또는 주요 변경 후

- [ ] 깨진 링크와 콘솔 오류 확인
- [ ] 문의·댓글 스팸 확인
- [ ] Pages 빌드 상태 확인
- [ ] 외부 서비스 대시보드의 경고 확인

### 매월

- [ ] 인기 페이지와 이탈 지점 검토
- [ ] 검색 노출 및 sitemap 처리 상태 확인
- [ ] 정책 문서와 실제 서비스 목록 비교
- [ ] 불필요한 외부 스크립트 제거 검토
- [ ] 접근성·성능 간단 점검

### 서비스 변경 시 즉시

- [ ] 코드와 정책 문서를 같은 변경으로 수정
- [ ] 검증 항목 추가 또는 제거
- [ ] 데이터 보관·삭제 절차 확인
- [ ] 사용자에게 중요한 변경 안내
